# ADR-012 — Scope and Progressive Complexity

Status: proposed · 2026-10-02

Context: a 151-section vision can produce many half-working pages. The user requires both personal simplicity and commercially useful employer workflows.

Decision: P0 two journeys, shared engines and fixed roles, bounded creation/AI, individual assignment/evidence/review/report. Hide deferred features entirely. M1 core works without AI; M2 adds validated real intelligent conversion and pilot evidence.

Alternatives: organization-only UI frustrates individual use; separate personal app duplicates progress; enterprise-first feature breadth postpones practical value. Removing review/report/import would turn the MVP into a different product.

Consequences: fewer initial features with genuine workflow depth. Teams, assessments, SSO, billing, certificates, public share links and deep AI remain explicit later scope rather than placeholder pages. Future functionality builds on versioned contracts.

Verification: fresh-personal no-company journey, employer revision/approval/report workflow, nontechnical content and complete P0/test mapping. [MVP](../docs/03-MVP-SCOPE.md) and [roadmap](../docs/21-DEVELOPMENT-ROADMAP.md).
