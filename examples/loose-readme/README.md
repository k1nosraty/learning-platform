# مسیر یادگیری کارآموز IT

این برنامه برای فردی است که C++ و Qt بلد است و می‌خواهد زیرساخت یک شرکت را بشناسد. زمان‌بندی دقیق را بعد از بررسی سطح فعلی تنظیم می‌کنیم.

## مرحلهٔ اول: شبکه

### مبانی

OSI، TCP/IP، IPv4 و subnetting را یاد بگیر. تفاوت TCP و UDP و نقش DNS و DHCP را توضیح بده.

### تمرین‌ها

- [ ] تنظیمات شبکهٔ سیستم خودت را بررسی و ثبت کن.
- [ ] یک packet capture آزمایشگاهی را تحلیل کن.
- [ ] یک سناریوی اختلال DNS بساز و روش تشخیصش را بنویس.

### پروژه

یک شبکهٔ کوچک آزمایشگاهی طراحی کن. شواهد شامل دیاگرام، آدرس‌ها و نتیجهٔ تست اتصال باشد. در حالت سازمانی، منتور باید پروژه را بررسی کند.

## مرحلهٔ دوم: سیستم‌های شرکت

Windows Server، حساب‌های کاربری و SQL Server را بررسی کن. ابزارها و منابع دقیق بعداً با نظر منتور انتخاب می‌شوند؛ این بخش هنوز تخمین زمان ندارد.

## یادداشت مهم

این متن منبع اولیه است. سیستم نباید عبارت‌های مبهم را به ادعای مهارت یا منابع تأییدشده تبدیل کند. ترتیب و جزئیات پیشنهادی را پیش از شروع یادگیری بررسی کن.
